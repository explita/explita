## About Me

I'm a software engineer passionate about building practical software, designing reusable abstractions, and solving problems through thoughtful engineering.

My work spans application development, backend architecture, developer tooling, and infrastructure. I enjoy working across the stack, understanding systems beneath the abstractions, and turning recurring engineering challenges into tools that other developers can use.

## 🚀 Explita Infra

**Developer infrastructure designed to help developers build, deploy, and connect applications.**

I'm building an ecosystem of tools that brings greater control and simplicity to the development and deployment workflow.

| Project                                                        | Description                                                   |
| -------------------------------------------------------------- | ------------------------------------------------------------- |
